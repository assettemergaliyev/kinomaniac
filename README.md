# Киноманьяк — AI Movie Recommendation System

Учебный проект по AI Engineering: система рекомендаций фильмов на основе локальной Large Language Model (LLM).

## О проекте

«Киноманьяк» принимает текстовый запрос пользователя на естественном языке и рекомендует от 1 до 3 фильмов из заранее подготовленного каталога `films.json`.

Для генерации рекомендаций используется локальная модель `qwen3.5:4b` через Ollama и OpenAI-совместимый API.

**Основные возможности:**
- Поиск фильмов по текстовому запросу на русском и казахском языках.
- Рекомендации только из локального каталога.
- Структурированные ответы с использованием Pydantic.
- Проверка существования `film_id` и отсутствия дубликатов.
- Обработка ситуации, когда подходящих фильмов нет (`no_match`).
- Журналирование запросов и результатов в `calls.jsonl`.
- Автоматические тесты с использованием pytest.

## Технологии

- Python 3.12
- Ollama
- Qwen 3.5 (`qwen3.5:4b`)
- OpenAI Python SDK
- Pydantic
- pytest
- uv

## Каталог фильмов

Каталог `films.json` содержит 50 фильмов, включая 10 казахстанских.

Для каждого фильма указаны идентификатор, название, год выпуска, продолжительность, жанры, страны, языки и краткое описание.

## Установка и запуск

### Требования

Для запуска проекта необходимы:

- Python 3.12
- uv — менеджер зависимостей Python
- Ollama — для локального запуска LLM
- Модель `qwen3.5:4b`

### 1. Установка зависимостей

Находясь в корневой папке проекта, выполните:

```powershell
uv sync --frozen
```

Команда устанавливает зависимости из `uv.lock` без обновления lock-файла.

### 2. Подготовка Ollama

Установите Ollama и загрузите модель:

```powershell
ollama pull qwen3.5:4b
```

Убедитесь, что Ollama запущена и её API доступен по адресу `http://localhost:11434`.

### 3. Запуск рекомендаций

Передайте текстовый запрос в качестве аргумента:

```powershell
uv run kino.py "Посоветуй фантастический фильм про космос"
```

Программа выведет до трёх рекомендаций с названием, годом, продолжительностью, описанием и объяснением выбора.

Если подходящих фильмов нет, программа вернёт результат `no_match`.

### 4. Проверка тестовых запросов

```powershell
uv run check.py
```

Команда последовательно отправляет запросы из `queries.json` локальной модели.

### 5. Просмотр статистики

```powershell
uv run show.py
```

Команда выводит статистику результатов из журнала `calls.jsonl`.

### 6. Автоматические тесты

```powershell
uv run pytest -q
```

Тесты проверяют корректность бизнес-валидации без обращения к Ollama.

## Эксперимент: проверка фактических знаний LLM

**Цель:** проверить, насколько точно локальная модель `qwen3.5:4b` определяет год выпуска и продолжительность фильмов без доступа к каталогу.

**Методика:** выбраны 10 фильмов из `films.json`. Модели передавалось только название фильма. Полученные ответы сравнивались с данными IMDb, проверенными для каждого фильма.

| Фильм | Год IMDb | Год LLM | Минуты IMDb | Минуты LLM |
|---|---:|---:|---:|---:|
| Интерстеллар | 2014 | 2014 | 169 | 140 |
| Побег из Шоушенка | 1994 | 1994 | 142 | 142 |
| Зелёная миля | 1999 | 1999 | 189 | 145 |
| 1+1 | 2011 | 2006 | 112 | 86 |
| Начало | 2010 | 2010 | 148 | 148 |
| Матрица | 1999 | 1999 | 136 | 137 |
| Форрест Гамп | 1994 | 1994 | 142 | 149 |
| Тёмный рыцарь | 2008 | 2008 | 152 | 154 |
| Бойцовский клуб | 1999 | 1994 | 139 | 127 |
| Криминальное чтиво | 1994 | 1994 | 154 | 110 |

### Результаты

- Точное совпадение года выпуска: **8/10 (80%)**.
- Точное совпадение продолжительности: **2/10 (20%)**.
- Оба значения совпали: **2/10 (20%)**.

Для фильма «Начало» модель указала правильные значения, но также предложила посторонний вариант, что свидетельствует о неоднозначности ответа.

### Вывод

В этом эксперименте модель значительно чаще правильно определяла год выпуска, чем продолжительность фильма. Некоторые ответы содержали фактические ошибки, несмотря на уверенную формулировку.

Поэтому в проекте «Киноманьяк» фактические характеристики фильмов берутся из проверяемого каталога `films.json`, а LLM используется для подбора рекомендаций и объяснения выбора.

Эксперимент проводился однократно на 10 фильмах. Полученные проценты не следует интерпретировать как универсальную оценку качества модели.
